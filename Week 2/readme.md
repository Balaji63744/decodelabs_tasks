# Week 2 - Exploratory Data Analysis (Power BI)

## Project Title
Exploratory Data Analysis (EDA) using Power BI

## Objective
The objective of this project is to perform Exploratory Data Analysis (EDA) on an employee dataset using Power BI. The project focuses on understanding the data, identifying trends, creating meaningful visualizations, and generating business insights through an interactive dashboard.

## Tools Used
- Microsoft Power BI
- Microsoft Excel

## Dataset
The dataset contains employee information, including:
- Employee ID
- Name
- Age
- City
- Department
- Salary

## Tasks Performed
- Imported the dataset into Power BI.
- Cleaned and transformed the data using Power Query.
- Calculated statistical measures such as Mean, Median, and Mode.
- Created KPI Cards for key metrics.
- Designed visualizations including:
  - Bar Chart
  - Pie Chart
  - Column Chart
  - Table
- Identified trends and outliers.
- Applied filters and slicers for interactive analysis.
- Built an interactive dashboard.

## Key Insights
- Analyzed employee distribution across departments.
- Compared salaries among different departments.
- Identified departments with the highest employee count.
- Visualized salary distribution and employee demographics.

- Employee_EDA.pbix

- Dashboard_Screenshot.png

## Outcome
Successfully created an interactive Power BI dashboard that provides clear insights into employee data through visualizations and KPIs.
