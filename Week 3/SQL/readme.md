# Week 3 - SQL Data Analysis

## Project Title
SQL Data Analysis using MariaDB

## Objective
The objective of this project is to perform data analysis using SQL queries. The project demonstrates the use of SQL statements to retrieve, filter, sort, group, and summarize employee data to generate meaningful insights.

## Tools Used
- MariaDB (XAMPP)
- SQL

## Dataset
The dataset contains employee information, including:
- Employee ID
- Name
- Age
- City
- Department
- Salary

## Tasks Performed
- Created a new database.
- Created the Employees table.
- Inserted employee records into the table.
- Retrieved data using SELECT statements.
- Filtered records using WHERE conditions.
- Sorted records using ORDER BY.
- Grouped data using GROUP BY.
- Used aggregate functions:
  - COUNT()
  - SUM()
  - AVG()
  - MAX()
  - MIN()
- Applied HAVING and BETWEEN clauses for advanced filtering.

## SQL Concepts Used
- CREATE DATABASE
- CREATE TABLE
- INSERT INTO
- SELECT
- WHERE
- ORDER BY
- GROUP BY
- HAVING
- COUNT
- SUM
- AVG
- MAX
- MIN
- BETWEEN

## Files Included
- SQL_Project.sql
- SQL_Output.pdf (or screenshots of query results)

## Outcome
Successfully performed SQL-based data analysis by creating a database, querying employee data, and generating meaningful insights using SQL aggregate and filtering functions.
